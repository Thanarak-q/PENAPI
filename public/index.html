Paste a raw HTTP response header block. Missing or weak security headers (CSP, HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy), tech-stack disclosure, and unsafe CORS are flagged.

Enter a Unix epoch (seconds or milliseconds) or an ISO 8601 date to see every representation and how long until / since it. Handy for JWT exp / iat claims.

      

        
        
      

      

      

        
        
      

    

  


  

    

      
Param Analyzer — triage query params

      
Paste a URL or query string. Each parameter is classified by the attack class its name/value suggests — open redirect, SSRF, path traversal, IDOR, secret, injection — so you know what to fuzz first.

      
      

      

        
        
      

    

  


  

    

      
Entropy Analyzer — measure one secret

      
Paste a single session token, API key, or nonce. Shannon entropy and an optimistic brute-force keyspace are computed from its length and character set — a quick check before you trust a value as a secret. For sampling many tokens, use Token Sequencer.

      
      

      

        
        
      

    

  


  

    

      
Redirect & SSRF Payloads — filter-bypass strings

      
Generate classic open-redirect and SSRF bypass payloads for an authorized test. Set your attacker/OOB host and the target host; nothing is sent — copy a payload into a redirect / url parameter yourself.

      

        
        
      

      

      

        
        
      

    

  


  

    

      
JSON Flattener — paths & leaked fields

      
Paste a JSON response to flatten it into dot.path[i] → value rows. Keys that look sensitive (password, token, api_key, email, …) are highlighted — useful for spotting leaks and locating a value to extract in a Sequence step.

      
      
      

      

        
        
        
      

    

  


  

    

      
Body Converter — JSON → form / query / multipart

      
Paste a JSON object to re-encode the same data as x-www-form-urlencoded, a query string, and multipart/form-data — for probing content-type confusion and parameter pollution. Nested values are JSON-encoded so they survive.

      
      

      

        
        
      

    

  


  

    

      
Injection Payloads — authorized testing cheat sheet

      
Categorized test strings for XSS, SQLi, path traversal, SSTI, and command injection. Set a marker to replace {{M}} (your OOB host or a unique reflection canary). Generation only — nothing is sent; copy a payload into a request yourself.

About Swaggernaut 

      
Pentest-oriented API workbench — loads an OpenAPI/Swagger spec and adds offensive testing tooling (repeater, fuzzer, access-control matrix, auth sweep, JWT toolkit).

      
Runs entirely on your machine. No telemetry and no external calls — requests go only to the targets you choose, and JWT decode/sign/brute-force all happen locally in your browser.

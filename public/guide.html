Swaggernaut Guide

Practical advice for using the workbench safely: load a spec, build requests, choose identities, then move from passive review to controlled active testing.

Start safely

  • Use Swaggernaut only on systems where you have explicit authorization to test.
  • Set the Target base URL before sending requests, and confirm the active identity before running matrix, sweep, fuzzer, or discovery actions.
  • Start with GET-only and passive views when testing a fragile environment. Treat POST, PUT, PATCH, and DELETE as potentially mutating.

Suggested workflow

  1. Load a spec. Use File -> Load Spec, then scan the sidebar for unauthenticated, deprecated, or body-heavy operations.
  2. Set identities. Create Admin, User, and Unauth header sets so matrix and sweep results have useful contrast.
  3. Review Attack Surface. Use the passive findings to pick likely BOLA, missing-auth, SSRF, and mass-assignment candidates.
  4. Repeat one request. Confirm baseline behavior in Request before sending it to Fuzzer, Access Matrix, or Sequence.
  5. Escalate carefully. Run Quick Attacks, Content Discovery, Auth Sweep, and Fuzzer only when the target and method are safe for active traffic.

Dark mode

The Dark button in the top bar switches the entire workbench to a low-glare palette. It is saved locally in your browser and applies to this guide page too.

Color palettes

The four swatches next to the target controls change the accent color. Use them to separate screen recordings, projects, or long sessions without changing request data.

Advice for active tools

Fuzzer
Mark one injection point with §value§ or FUZZ. Keep concurrency low until you know the endpoint is stable.
Access Matrix
Best for one request at a time. A low-privilege or unauthenticated 2xx response is the signal to investigate.
Auth Sweep
Use GET first. Add mutating methods only when the target environment can tolerate repeated writes.
Content Discovery
Runs real GET requests against the base URL. Keep custom wordlists focused and stop when noise outweighs signal.

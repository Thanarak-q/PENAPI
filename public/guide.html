Quick start

Start safely

Authorized testing only. Swaggernaut sends real traffic from the host running it. Confirm permission, target, identity, and request count before active tools run.
  1. Load a spec Use File -> Load Spec..., pass a file or URL to the CLI, or paste a spec at runtime.
  2. Set the target Check the Target base URL before every run. A wrong base URL is the easiest way to test the wrong system.
  3. Create identities Keep at least Admin, User, and Unauth profiles so access checks have useful contrast.
  4. Baseline one request Send a normal request first, then compare fuzzer, matrix, or quick-attack results against that baseline.

Workflow

Suggested workflow

Passive first

Start in Explorer and Attack Surface. Every finding is mapped to the OWASP API Security Top 10 (2023) with a CWE and a confidence, and the view shows an overall risk score, posture grade, an Unauth writes ratio, and per-endpoint risk pills in the sidebar. Triage High findings first, then export a Markdown report.

Send a few requests, then re-check

The Attack Surface also mines your saved request log: permissive/credentialed CORS, weak cookie flags, tech-fingerprint banners, verbose stack traces, JWT alg=none/no-exp tokens, PII/secrets in responses (masked), reflected input, open redirects, GraphQL introspection, and cookie-auth requests missing CSRF tokens. Send a handful of authenticated requests, then revisit the tab.

Repeat before testing

Open one operation in Request, fill generated params, inspect headers, and confirm the normal response shape before sending it anywhere else.

Escalate one tool at a time

Use Access Matrix for role contrast, Sequence for stateful flows, and Fuzzer only after the endpoint is stable enough for repeated traffic.

Active testing

Attack tools

Fuzzer

Mark one injection point with §value§ or FUZZ — or use Insert §§ / Auto-mark to place one. Load the current request and the Fuzzer suggests the most relevant payload sets for its shape (click a chip to select one). Start with low concurrency and a small set, then click 🔍 on any result to inspect its full response in a popup.

Access Matrix

Replay the same request as every identity. A low-privilege or unauthenticated 2xx response is the signal to investigate.

Sequence Runner

Capture values from earlier responses and reuse them later with {{name}}. Use this for BOLA, token refresh, and multi-step flows.

Content Discovery

Runs real GET requests against the base URL. Keep wordlists focused and stop when noise outweighs signal.

Quick Attacks

Tries controlled mutation variants: missing auth, method override, path normalization, framework ACL bypasses (; matrix param, /..;/, .json), content-type confusion, spoofed forwarding headers, and a mass-assignment body probe.

Auth Sweep

Maps authorization coverage across many endpoints. Use GET first and review the estimated request count before confirming.

Appearance

Dark mode and color palettes

Dark mode

The Dark button in the top bar switches the workbench to a low-glare theme. It is saved locally and applies to this guide page too.

Color palettes

The four swatches next to the target controls change the accent color. Use palettes to separate projects, screen recordings, or long sessions.
